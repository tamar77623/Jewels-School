# 🏫 Jewels School - Landing Page

A **professional, modern, and fully responsive landing page** for "Jewels School." It is designed to provide parents and visitors with core information about the school's vision, culture, and educational offerings, featuring an integrated system to book appointments with the school manager.

---

## 🚀 Features

*   **Fully Responsive Design:** Seamlessly adapts to all screen sizes (mobiles, tablets, and desktops) using Tailwind CSS utility classes.
*   **Smooth Scrolling:** Enhanced user experience with fluid, animated navigation between page sections (`scroll-smooth`).
*   **Interactive Appointment Booking:** A dedicated form capturing essential visitor details (Full Name, Phone Number, Email, Date, Time, and Purpose of Meeting).
*   **Sticky Navigation Bar:** Remains accessible at the top of the viewport while scrolling, featuring smooth hover states.

---

## 🛠️ Tech Stack

*   **HTML5:** Structured semantic markup optimized for accessibility.
*   **Tailwind CSS:** Modern utility-first styling frameworks loaded efficiently via CDN.
*   **JavaScript (main.js):** Custom dynamic behaviors, form validation, and submission feedback handling.

---

## 📝 Page Sections

1.  **Header:** Contains the school logo and instant navigation links.
2.  **About the School:** A welcoming introduction highlighting academic excellence and character building.
3.  **Who We Are:** Deep dive into the institution's core mission, values, and environment.
4.  **What Our School Offers Your Child:** Showcases how the community nurtures tomorrow's leaders.
5.  **Book an Appointment:** An interactive layout built to request direct meetings with the manager.
6.  **Footer:** Displays standard copyright and developer attribution metadata.

---

## 💻 How to Run the Project

1. Clone or download this repository to your local machine.
2. Open the `index.html` file directly in any modern web browser (e.g., Google Chrome, Mozilla Firefox, Microsoft Edge).
3. Ensure you have an active internet connection so that the **Tailwind CSS CDN** and **Flaticon** assets load properly.
